New connection update

Screen sharing uses UDP WebRTC media with adaptive quality. Text, taps, scrolling and keys use ordered, end-to-end encrypted TCP controls. Send keeps your text until the PC acknowledges acceptance. If a connection drops before confirmation, check the PC before sending again.

Update both Windows and Android to preview 11. Mixed old/new remote versions cannot finish this connection. Your saved devices are retained when updating over the existing apps.

Pair once. Approve on your PC.

  1. Get your key

    On Windows, choose what to share and tap Generate connection key.

  2. Enter six characters

    Type that key into the Android app. There are no router settings or server addresses to enter.

  3. Allow your phone

    On the PC, review the request and tap Allow this phone. Trusted reconnect is optional.

Closing or minimizing the Windows preview keeps it in the tray. Use Stop remote sharing or Disconnect and quit from its tray menu to stop. The PC must be awake and online.

Optional Windows startup

Preview 9 adds Start DeviceBridge after Windows sign-in on the PC’s Android-control screen. It is off by default. When you enable it, DeviceBridge opens in the tray after you sign in; only existing approved phones with reconnect permission can reconnect. The PC must be awake and online.

Updating is simple.

On Android: open App updates → Check for updates → Download update → Install update. Review Android’s installation prompt, then reopen DeviceBridge. Update over the existing app to retain saved devices.

On Windows: use Disconnect and quit in DeviceBridge’s tray menu, then run the new installer over your current copy. Open the desktop shortcut when setup finishes. The desktop connection pauses during the update.

What we are testing

Physical Android-to-Windows screen viewing and basic typing are user-confirmed on the same Wi-Fi. The phone successfully updated to preview 7 through App updates. Preview 8 adds Windows Main menu/Continue navigation and Android pinch zoom, two-finger pan and Fit screen. Automated checks pass: 99 native Windows, 134 shared and 14 Android native tests, plus isolated Windows installer and portrait/landscape zoom layout checks. The user reports preview 8 is working. The user has now confirmed mobile-data screen access, automatic recovery after PC internet loss, phone lock/background recovery and PC audio on Android. The microphone button now toggles on Android, but two PC virtual-microphone level checks detected no signal. Actual microphone delivery remains under investigation. The new UDP/TCP transport still needs physical acceptance.

Some networks may prevent a direct connection; a relay is not configured yet. The free preview service can take a minute to wake up. If a screen connection stalls, use Check connection → Show connection report on both apps. This preview is separate from the stable 0.8.0 Windows release.

The Windows app is not code-signed yet, so SmartScreen may show a publisher warning. Android may ask whether to allow installing this APK. Keep system protections enabled; do not continue if your security software blocks it. Microphone routing uses the included VB-CABLE setup and may require a restart.
