Updating an existing installation

Windows: choose Disconnect and quit in DeviceBridge’s tray menu, then run this Windows installer over the existing app. Reopen the desktop shortcut. Android: use App updates → Check for updates → Download update → Install update. Approve Android’s installation prompt and reopen the app. Keep both devices on the same preview version.

Requirements and current limits

Windows 10/11 x64 and Android 8+ are build targets. Physical screen access, basic typing, PC sound, mobile-data access and reconnect after an internet interruption are confirmed. Detailed preview 11 transport and older-device tests remain open. Phone microphone is on hold; Mac and iPhone apps are deferred. Restrictive networks may need a relay, which is not configured yet.

If the connection needs help

Keep both apps open and on the same version. A new pairing key lasts two minutes, and the PC must approve the phone. The free connection service may take a minute to wake. Use Check connection → Show connection report on both apps if the screen stays blank. The live checklist records what is verified and what remains.

BEFORE YOU DOWNLOAD

Clear answers.
Less guesswork.

A few things to know about setting up your shared desk.

Open the two-PC test guide ↗
Do I need to download anything else?

The Windows installer includes the app runtime. Download only the Windows installer for each PC and, for phone access, the Android app shown above. Screen viewing, typing and PC sound do not require microphone-driver setup. The included driver is optional for local Windows microphone sharing; phone microphone is on hold.

Can one PC use Ethernet and the other Wi-Fi?

Yes. Both PCs need to be on the same trusted local network. Guest networks and router isolation can block communication. If pairing needs help, use “Fix connection / network access” beside the key. No router port forwarding is needed.

How do I use the shared microphone in calls?

For local Windows-to-Windows sharing, choose the desk microphone in DeviceBridge and CABLE Output in the receiving PC’s calling app. This is separate from Android remote access. The phone microphone is on hold; keep Microphone off on Android. No microphone-driver setup is needed just to view the PC screen or type from your phone.

What happens when I close the window?

An active or waiting session continues in the system tray. Reopen DeviceBridge or double-click its tray icon to restore the window. Choose “Disconnect and quit” from the tray menu when you want to exit. Ctrl+Alt+Esc stops sharing immediately.

Will Windows show a publisher warning?

Windows may show an unknown-publisher warning for an unsigned build, or a SmartScreen warning for a new file. Check the release notes for that version’s signing status. Installing the included microphone driver also needs administrator approval.

Which Windows PCs are supported?

The download is for Windows 10 and 11, 64-bit, with one connected PC pair. Audio capture without a physical playback device needs Windows build 20348 or later, including Windows 11. Older Windows uses a physical playback endpoint. Secure Windows screens and elevated apps cannot be controlled.

Can I control my PC from Android?

Yes. Download both apps in the Windows + Android section above. Install its Windows app and Android companion, enter the six-character key, then approve the phone on the PC. Your computer must stay awake and online. Screen access has been confirmed on the same Wi-Fi and with the phone on mobile data. Trusted reconnect has also been confirmed after the PC regains internet. Some restrictive networks still need a relay, which is not configured yet.

How do I zoom or return to the main menu?

In the Android preview, pinch the PC view to zoom, move with two fingers, and tap Fit screen to reset. On Windows preview 8 or later, use ← Main menu and Continue to move between screens while sharing keeps running. The phone setup guide is on this page.

Does sharing use a cloud server?

Local Windows-to-Windows sharing stays on your network. Android remote access uses an online service for pairing, reconnect and encrypted TCP controls. The screen and PC sound use encrypted UDP media between the devices when the network allows it. No account is needed. Keep your connection key private.
